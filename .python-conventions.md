## Writing-python PostToolUse opt-in (local only)

- Claude and Codex load plugin-owned hooks. Grok first requires `hooks/grok/install_grok_hooks.sh`
  to install its native global hook.
- After the host hook is available, create an **empty, gitignored** file at
  `.claude/writing-python-gate.local`. Do not commit it (the helper refuses a tracked marker).
- The opt-in marker is persistent until you remove it. This persistent marker enables the installed
  Grok hook as well as the Claude and Codex hooks. Without it, the hook is a no-op. Silence or exit-2
  is unknown, not green.
- Claude, Codex, and Grok run Stop only after the same host touched an existing Python file in the
  same repo and session. The Python-touch ledger entry is one-shot. Bash-only activity stays silent.
- Codex loads plugin-owned hooks from `hooks/codex/hooks.json`. Its `systemMessage` warnings are
  visible in the UI/event stream, not model-visible completion evidence. After installing or
  changing hooks, start a fresh session and approve changed plugin hook definitions in `/hooks`.
- The repository installer removes any legacy inline Codex block after installing the plugin.
  `hooks/codex/install_codex_hooks.sh --rollback` restores that block for recovery only.
